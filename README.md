# FinDev Market Dashboard

An Angular dashboard that displays market metrics calculated in a Web Worker
from trades generated by Rust/WebAssembly.

## Local setup

Install Node.js 24 LTS and Rust with Cargo via rustup. From the repository root:

```sh
npm ci
npm run build:wasm
npm start
```

Open http://localhost:4200/. Run `npm run build:wasm` again after
changing the Rust generator. It creates the JavaScript bindings and Wasm
binary in `wasm/market-generator/pkg`, which is ignored by Git.

## Build and test

After generating the Wasm package, run:

```sh
npm test
cargo test --locked --manifest-path wasm/market-generator/Cargo.toml
npm run build
```

`npm test` runs the Angular and Web Worker test suites. The production site is
written to `dist/findev-market-dashboard/browser`, including the Wasm binary.

Cloudflare Pages uses `npm run build` and publishes
`dist/findev-market-dashboard/browser`. The build generates Wasm before
compiling Angular and installs Rust on Cloudflare if rustup is unavailable.
